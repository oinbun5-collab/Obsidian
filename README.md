# Obsidian Blog

Obsidian으로 글을 쓰고 GitHub Pages로 발행하는 블로그.

## 구조

- `Obsidian/` — 콘텐츠 작성 (Vault로 열어서 사용)
  - `Raw/` — 생각 그대로 적는 곳
  - `Wiki/` — 정리된 글 (블로그로 옮길 것)
  - `Index.md` — 목차 + 기획 4질문
- `docs/` — GitHub Pages 라이브 사이트
  - `index.html` — 홈
  - `about.html` — About
  - `posts/` — 글 페이지
  - `style.css` — 스타일
